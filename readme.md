## 安装方法

关闭 SimplePlanes 2。
确认游戏目录已经安装 BepInEx 5 Mono x64。
解压 SimplePlanes2TranslationMod-Release.zip。
把压缩包里的 BepInEx 文件夹和 mod.json 放进 SimplePlanes 2.exe 所在目录。
启动游戏。
安装成功后，插件会位于：

SimplePlanes 2\BepInEx\plugins\SimplePlanes2Translation
使用
启动游戏后会自动汉化。

快捷键：

F1：临时开关汉化，方便对照原文和截图反馈。
F2：重新加载汉化配置和词表。纯文本翻译更新后可以按这个键热重载。
正常游玩不需要打开任何额外程序。

## 卸载方法

关闭游戏后，删除：

SimplePlanes 2\BepInEx\plugins\SimplePlanes2Translation
